# Global Superstore Data Analysis

## Project Overview
This project focuses on analyzing Global Superstore sales data to understand business performance and identify useful insights.

## Dataset
The dataset contains information about:
- Orders and sales
- Products and categories
- Customers and segments
- Regions and countries
- Profit and discounts
- Shipping details and returns

## Tools Used
- Microsoft Excel

## Project Objectives
- Analyze overall sales and profit.
- Compare sales across regions.
- Identify top-performing product categories.
- Understand customer purchasing patterns.
- Analyze returns and shipping performance.

## Project Files
- Excel workbook containing the dataset, analysis and dashboard.

## Key Learnings
This project helped develop skills in data analysis, understanding business performance and presenting data through Excel.
